Hyperlinks have text that we see and a URL to which we should go when the link is "actioned". The syntax is a pair of square brackets denoting the viewable text immediately followed by a pair of parentheses denoting the URL. I'll reproduce the link from the top of this file to a more complete markdown syntax reference: [markdown syntax](https://daringfireball.net/projects/markdown/syntax)
