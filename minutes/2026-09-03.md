Dynamic Application: has at least a Server, User Database, and generates a personalized response before sending the content to the user.  

    Before, servers just responded files to the client.  Now in 347, when a request is made, when you reach the server, the server does some stuff. Like for example, accessing a database.  The server can then send the response back to the client in html.  So the response can be successfully rendered to the user in the browser

    With servers, we can also persist states and share data.  We can also have "secrets" from the client.
    
    Business Logic - Guidelines a business has for operating stuff.  We can divide the concerns of an application.  Business Logic are the necessary rules for the transaction to take place and go as intended.  For example, you do form validation to make sure a user put in a valid age.  To ensure the user doesn't bypass this validation, you can have the validation code on the server side  as well as the client side
