## classroom 50 cli

1. [install github cli](https://cli.github.com/)
2. install classroom 50 cli
    ```sh
    gh extension install foundation50/gh-student
    ```
3. tell your gh classroom50 you're a student in this class
    ```sh
    gh student login
    ```
4. Just a quick test we will throw away immediately
    ```sh
    gh student accept CS-347-F26 347f26 kahoot
    ```

    1.  who is going to be the founder (just one of you)
        1. founder: 
    2. what your team name will be

            ```sh
            gh student accept CS-347-F26 347f26 kahduke --new-team --team-name "YOU_TEAM_NAME"
            ```

        2. founder add the rest of the table
            ```sh
            gh student team add CS-347-F26 347f26 kahduke TEAMMATE_GH_USERNAME
            ```
