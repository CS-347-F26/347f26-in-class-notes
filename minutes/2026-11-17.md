### Validation

1. Why should we validate user input?
    1. for improved user experience, it's hard to communicate precisely and unambiguously, sometimes we're misunderstood
        1. user is trying to provide the information correctly, but didn't understand
        2. implementing clientside input validation is very nice UX because the user doesn't have to wait for a roundtrip to the server to learn we're miscommunicating
            1. but it's not enough...

#### Clientside (343)

* html have an attribute
    * required
    * type (number)
    * other attrs
        * min, max
        * pattern? regex

What are the limits of clientside input validation?

* user can use devtools or userscripts to remove the validation features

What do we do?

* have to have serverside validation since we can't trust the client

#### Serverside Validation (347)

One of the biggest issues for user input is about security: injection attacks or other cases of trusting the user input.
Django helps with many of these by default.
To learn more about best practices for securing your django app, check out [the cheatsheet](https://cheatsheetseries.owasp.org/cheatsheets/Django_Security_Cheat_Sheet.html)

For more information about validating user input in django and django ninja, read or review:
